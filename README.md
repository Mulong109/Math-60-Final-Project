CC_increase.py provides the code for the increase update of the trust, CW_decrease provides the code for the decrease update of the trust, and Uncertain_move.py provides the code for random fluctaration.
In Individual_Simulation.py, we simulate the changes of trust for an individual.
In Percent_Dist.py, we simulate the change of trust for 1000 people. The pictures in the paper are produced by this section.
